## Файлы

| Файл | Назначение |
|---|---|
| `make_data.py` | генератор данных варианта (от преподавателя, не изменялся) |
| `store.py` | чтение и запись данных в `data/` (от преподавателя, не изменялся) |
| `iam.py` | задания 1–3: транслит и логины, новые сотрудники, парольная политика, генерация паролей, ролевая модель, создание учётных записей |
| `check_passwords.py` | задание 2: генерация и проверка 1000 паролей |
| `role_matrix.csv` | задание 3: матрица «должность × право» |
| `audit.py` | задание 4: аудит (уволенные, «осиротевшие», неактивные, лишние права, конфликты SoD) |
| `fix.py` | задание 5: отключение учётных записей, отзыв лишних прав, создание учётных записей |
| `logwatch.py` | задание 6: подбор пароля, входы в нерабочее время, входы в отключённые учётные записи |
| `.gitignore` | исключает `data/` и `__pycache__/` |

## Порядок запуска (из папки practice4)

```bash
python make_data.py          # ввести 6 — создаётся папка data/
python check_passwords.py    # задание 2
python iam.py                # задания 1–3: role_matrix.csv и учётные записи новым сотрудникам

python make_data.py          # 6 — исходные данные перед аудитом
python audit.py              # задание 4: все строки OK

python fix.py                # задание 5
python audit.py --after-fix  # все значения 0 -> OK

python logwatch.py           # задание 6: все строки OK
```
